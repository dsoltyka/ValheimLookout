# Changelog

## 1.0.0

- Initial release.
- Minimap pins for dungeon entrances out of the box; every item is opt-in.
- In-game panel (F7 or the button on the large map) listing every item the world can yield, with per-item opt-in, a filter, and live nearby counts.
- Only-discovered mode (on by default) keeps undiscovered items out of the panel and off the map.
- Optional surface locations, buried-deposit and explored-only modes, distance limit, labels and icon size.
- Config file edits are picked up live while the game is running.
